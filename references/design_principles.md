# 装修设计原则与避坑指南

## 60-30-10 配色法则

全屋配色按 60:30:10 比例分配三种角色色：

- **主色 60%**：墙面、顶面、大面积地面。决定整体调性，必须全屋统一。
- **辅色 30%**：地板、大型家具（沙发/床/衣柜）、窗帘。与主色同色系不同深浅，制造层次。
- **点缀色 10%**：抱枕、装饰画、花瓶、灯具金属件。允许小范围跳色，但色相差异不超过 5%。

### 常见错误

- 三种角色色面积均等 → 没有主次，视觉混乱
- 每个房间用不同主色 → 全屋割裂，显廉价
- 点缀色面积超过 15% → 失去点缀作用，变成第二个主色

## 墙浅→地中→家具深

竖向空间的色彩层次法则：

- **墙（浅）**：视觉最远，用最浅色拉开空间感
- **地（中）**：视觉居中，用中间色稳住重心
- **家具（深）**：视觉最近，用最深色增加重量感

逆向使用（墙深地浅）会让空间头重脚轻，显压抑。

## 灯光色温分层

每间房至少三回路，色温分层：

| 回路 | 色温 | 用途 | 亮度 |
|------|------|------|------|
| 主灯 | 4000K | 日常活动、打扫 | 高 |
| 氛围灯 | 3000K | 灯带/落地灯/吊灯 | 低 |
| 阅读灯 | 3000K | 床头壁灯/沙发旁 | 中 |

### 常见错误

- 一灯到底（只有主灯）→ 没氛围，像办公室
- 全屋 6000K 冷白 → 显冷、像医院
- 主灯太亮（>100lm/m²）→ 毁掉所有氛围
- 强行做无主灯方案 → 翻车高发，详见下方「无主灯」专章

## 无主灯方案：能做，但有 5 个前置条件

朋友（实踩过坑的装修人）的核心反馈：**没有专业设计能力和对应工艺，强行做无主灯容易翻车**。这话非常中肯。这章把这件事讲透。

### 什么是无主灯

取消传统吸顶灯/吊灯作为主光源，改用**全屋分散的点光源 + 灯带**做照明组合（筒灯 + 射灯 + 灯带 + 落地灯 + 壁灯）。视觉上更极简、更有层次，是这两年小红书爆火的网红设计。

### 为什么容易翻车

无主灯不是"不要装主灯"那么简单，本质是**全屋灯光重新设计**，对以下 5 件事有硬要求：

1. **顶面工艺**：必须做吊顶（局部或全顶），最少降 8-12cm 层高。层高低于 2.7m 不建议做全顶无主灯。
2. **灯位精确设计**：每个筒灯/射灯的位置、间距、开孔尺寸都要精确到厘米，**不是凭感觉**。
3. **灯光回路复杂**：常规 1-2 回路不够，至少 3-5 回路（基础照明、重点照明、氛围照明分组控制）。
4. **预算翻倍**：传统主灯方案 1000-3000 元搞定客厅，无主灯方案灯具+吊顶+电路改造通常 8000-20000 元。
5. **需要专业灯光设计师出图**：不是装修公司设计师免费送的，是按平方收费的专业设计（通常 50-150 元/㎡）。

**翻车典型场景：**

- 筒灯间距不一，光斑像麻子脸
- 灯带照墙不均，一道亮一道暗
- 没考虑窗帘盒/柜子遮光，光源被遮挡变成奇怪阴影
- 色温没规划，3000K 和 4000K 混用，发黄发蓝
- 沙发上方没灯位，看书靠落地灯补救，结果落地灯位置被茶几挡了

### 自检清单：你能做无主灯吗？

回答以下 5 个问题，**全部 "是" 才建议做**：

| 检查项 | 是 | 否 |
|--------|----|----|
| 层高 ≥ 2.7m？ | ✅ 可做全顶 | ❌ 只做局部 |
| 预算愿意翻倍（+1 万左右）？ | ✅ 可做 | ❌ 别做 |
| 愿意请独立灯光设计师？ | ✅ 可做 | ❌ 别做 |
| 装修公司有专业灯光设计经验？（看 3 个以上完工案例） | ✅ 可做 | ❌ 别做 |
| 接受工期延 2-3 周？ | ✅ 可做 | ❌ 别做 |

### 4 个更稳的替代方案

如果上面有 1-2 项 "否"，推荐用替代方案，效果接近但翻车概率低 80%：

**A. 主灯 + 辅灯组合**（最推荐）
- 保留客厅主灯（吸顶灯或吊灯），色温 4000K
- 加落地灯 + 灯带做氛围
- 厨房/卫生间用筒灯补充
- 总预算 3000-5000 元全屋搞定

**B. 局部无主灯**
- 只在**不主灯位的区域**做（背景墙、过道、玄关）
- 主活动区保留主灯
- 视觉有层次，但风险可控

**C. 简化无主灯（最低成本）**
- 不做吊顶，用**明装筒灯/轨道灯**直接装原顶
- 层高不损失，但顶面不如暗装美观
- 适合预算紧、不想吊顶的户型

**D. 主灯 + 智能调光调色**
- 保留主灯，但选**支持 2700K-6500K 无极调色**的 LED 吸顶灯
- 米家/HomeKit/天猫精灵控制
- 一盏灯搞定氛围，但牺牲无主灯的极简感

### 网红设计陷阱

朋友另一条反馈："反正挺多网红设计，都不是那么容易落地的"。这是事实。三个识别技巧：

1. **看发布者**：小红书/抖音上很多"自家装修"其实是设计公司软广。点开主页看是不是每篇都是装修 + 引流到工作室。
2. **看滤镜强度**：背景虚化 + 高饱和度 + 暖光的图基本是摆拍和精修，实物落地后层高、采光、材质都跟图不一样。
3. **看预算标注**：真正落地过的博主会写"硬装 XX 万、家具 XX 万"，含糊标"几万搞定"的多半有水分。

**简单原则：网红设计要模仿，先看 3 个真实落地的踩坑帖，再决定。**

### 本 Skill 的默认推荐

考虑到大多数用户是**自装 + 中等预算 + 无专业灯光设计**，本 Skill 默认走**「主灯 + 辅灯组合」方案（替代方案 A）**。如果你明确说"我要做无主灯"，我会先让你完成上面 5 项自检，确认后再出方案。

## 表面质感选择：光面 vs 麻面

光面（亮面/抛光/烤漆）和麻面（哑光/磨砂/吸塑）的选择不是审美问题，是功能问题。选错了要么难打理，要么滑倒，要么显暗。

### 核心判断逻辑

先回答三个问题，答案决定质感：

1. **这个面要不要沾水？** 沾水 → 必须麻面（防滑）
2. **这个面要不要沾油？** 沾油 → 必须光面（好擦）
3. **这个面会不会被刮？** 被刮 → 选麻面（划痕不明显）

### 分材质决策表

#### 地砖

| 场景 | 推荐质感 | 原因 |
|------|----------|------|
| 卫生间地面 | 麻面/哑光 | 防滑，湿水不摔 |
| 厨房地面 | 麻面/哑光 | 油渍+水渍，防滑优先 |
| 阳台地面 | 麻面/哑光 | 雨水会进来，防滑 |
| 客餐厅地面 | 光面或麻面均可 | 看采光和风格 |
| 暗厅/小客厅 | 光面 | 反光增亮显大 |
| 大客厅/采光好 | 麻面 | 无光污染，高级感 |

**禁忌：** 卫生间/厨房/阳台地面**绝不用光面砖**——沾水变溜冰场。

#### 墙砖

| 场景 | 推荐质感 | 原因 |
|------|----------|------|
| 厨房墙面 | 光面 | 油烟一擦就净，麻面会渗油 |
| 卫生间墙面 | 光面 | 水渍好擦，皂垢不渗 |
| 客厅背景墙 | 麻面 | 无光污染，漫反射柔和 |

#### 柜门

| 场景 | 推荐质感 | 原因 |
|------|----------|------|
| 现代/轻奢风 | 光面烤漆 | 显档次、反光增亮 |
| 极简/奶油风 | 麻面吸塑 | 质感内敛、不留指纹 |
| 有小孩家庭 | 麻面吸塑 | 划痕不明显 |
| 厨房橱柜门 | 麻面 | 光面烤漆留指纹和油渍 |
| 衣柜门 | 麻面或光面均可 | 看整体风格搭配 |

**注意：** 光面烤漆柜门**必留指纹**，厨房和卫生间柜门慎用。哑光吸塑柜门虽然不显指纹，但**颜色会比光面深半个色号**，选色时要在麻面色卡上选，不能拿光面色卡对照。

#### 台面（石材/岩板）

| 场景 | 推荐质感 | 原因 |
|------|----------|------|
| 厨房操作台 | 光面/抛光 | 油污不渗，好擦洗 |
| 餐桌台面 | 光面/抛光 | 汤渍好擦 |
| 卫生间台面 | 光面/抛光 | 水渍好擦 |
| 装饰墙台面 | 麻面 | 无光污染 |

**禁忌：** 厨房台面**绝不用麻面岩板**——渗油后会发黄发黑，无法清洁。

#### 木地板

| 场景 | 推荐质感 | 原因 |
|------|----------|------|
| 全屋地面 | 哑光 UV 漆 | 半哑光，不反光也不渗污 |

木地板基本都是 UV 漆面，市面分"高光"和"哑光"两种：

- **高光**：反光强，显亮但留划痕，**不推荐**（除非预算极高选 UV 高光多层）
- **哑光**：漫反射，质感好，划痕不明显，**默认选这个**

#### 墙漆

| 场景 | 推荐质感 | 原因 |
|------|----------|------|
| 全屋墙面 | 哑光乳胶漆 | 漫反射，无光污染，高级感 |
| 厨卫墙面 | 丝光/半光漆 | 防水好擦洗 |
| 顶面 | 哑光 | 不反光，不压顶 |

**注意：** 客厅墙面**不用丝光漆**——灯光打上会有一条条反光带，像办公室。哑光漆是家装默认选择。

### 全屋质感搭配原则

| 风格 | 地面 | 柜门 | 台面 | 墙面 |
|------|------|------|------|------|
| 现代暖灰 | 光面砖或哑光地板 | 光面烤漆 | 光面岩板 | 哑光漆 |
| 极简白 | 麻面砖 | 麻面吸塑 | 麻面岩板 | 哑光漆 |
| 奶油风 | 哑光地板 | 麻面吸塑 | 光面岩板 | 哑光漆 |
| 轻奢 | 光面砖 | 光面烤漆 | 光面大理石 | 哑光漆 |
| 原木风 | 哑光地板 | 哑光饰面板 | 麻面岩板 | 哑光漆 |

规律：**现代/轻奢偏光面（显档次），极简/奶油/原木偏麻面（显质感）。** 但厨卫功能区域永远按功能选，不按风格选。

### 常见错误

1. **卫生间地面用亮面砖** → 沾水变冰场，摔跤高危
2. **厨房台面用麻面岩板** → 渗油发黄，无法清洁
3. **客厅墙用丝光漆** → 灯光反光像办公室
4. **厨房柜门用光面烤漆** → 留满指纹，擦不干净
5. **全屋地面高光地板** → 划痕全显，住半年像旧房

## 风格特征要素

### 现代暖灰

- 墙：菱花白/象牙白
- 地：深胡桃复合 / 浅灰亮面砖
- 柜：象牙白烤漆
- 点缀：奶咖 + 哑黑 + 古铜金
- 软装：暖灰布艺 + 焦糖棕皮

### 极简白

- 墙：纯白
- 地：浅灰亮面砖
- 柜：纯白哑光
- 点缀：浅灰 + 哑黑
- 软装：灰白黑三色，无图案

### 奶油风

- 墙：菱花白/奶油白
- 地：浅原木复合
- 柜：奶油白
- 点缀：焦糖棕 + 奶咖
- 软装：弧形家具、绒布、暖光

### 轻奢

- 墙：菱花白
- 地：深灰大理石纹砖
- 柜：烤漆白 + 古铜金条
- 点缀：古铜金 + 墨绿
- 软装：丝绒、金属、大理石

### 原木风

- 墙：菱花白
- 地：白橡木复合
- 柜：白橡木本色
- 点缀：薄荷绿 + 原木
- 软装：棉麻、藤编、绿植

## 地区适应性

### 华南（潮湿/回南天）

- 地板：复合多层 UV 漆，不用纯实木（胀缩缝）
- 墙面：乳胶漆优于壁纸（防霉）
- 柜内：预留除湿棒孔位
- 瓷砖：优先亮面砖（防滑好打理）
- 窗帘：选短绒或无绒（长绒吸潮）

### 华东（梅雨）

- 地板：复合或实木复合，不用纯实木
- 墙面：乳胶漆 + 防霉底漆
- 柜体：颗粒板优于密度板（防潮）

### 华北（干燥/暖气）

- 地板：纯实木可用（稳定性好）
- 墙面：乳胶漆或壁纸均可
- 加湿：预留加湿器插座

## 常见避坑清单

1. **衣柜通顶深色** → 压抑。改：上 2/3 白门 + 下 1/3 深色开放格
2. **电视墙全空** → 寡淡。改：刷点缀色 + 哑黑地台
3. **沙发背景墙刷深色** → 显矮。改：保持浅色，用装饰画做层次
4. **一灯到底** → 无氛围。改：三回路（主灯+灯带+壁灯）
5. **明线走墙** → 难看。改：电视墙/床头墙预埋 50 管
6. **深色顶面** → 压顶。改：顶面永远最浅色
7. **地面拼花过多** → 显乱。改：全屋通铺一种砖/地板
8. **窗帘杆明装** → 矮化层高。改：窗帘盒隐藏
9. **踢脚线跟门套不同色** → 割裂。改：踢脚线跟门套或跟地板同色
10. **卫生间用木门** → 发霉。改：铝合金门或玻璃门

## 户型分析要点

看户型图时识别以下要素：

1. **朝向**：南向采光好可省纱帘；北向偏暗，墙漆选偏暖白
2. **楼层**：高楼层采光好，可选深色地板；低楼层偏暗，选浅色
3. **面积**：小户型选浅色系（显大）；大户型可用深色（显沉稳）
4. **层高**：低于 2.6m 不吊满顶，走边顶或石膏线
5. **动线**：客餐厅一体时，地面必须通铺（不分区域）

## 采购优先级

1. 先定地板和墙漆（最大面积，定基调）
2. 再定柜体板材（跟地板同色系）
3. 石材/岩板跟柜门同时定（台面要跟柜门搭配）
4. 灯具和五金同时定（金属件色系统一）
5. 最后定软装（抱枕/窗帘/地毯，点缀层可慢慢挑）
