# 装修配色与材料设计 Skill

> 输入户型图 + 风格偏好，输出全屋统一的配色方案、材料清单和立面示意图。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## 这是什么

一个面向 **WorkBuddy**（或其他兼容 Skill 协议的 AI 助手）的装修设计 Skill。

传统装修方案的痛点：

- 设计依赖装修公司或设计师，方案落地后才发现材料五花八门、风格不统一
- 配色调性凭感觉，房间之间割裂
- 材料采购没有清单，去建材市场被忽悠
- 灯光、质感、避坑全靠自己记

这个 Skill 把整套方法论固化进去——**60-30-10 配色法则、全屋材料统一、光面/麻面决策、灯光分层、地区避坑**，按风格出 5 套模板。

## 适用场景

- 拿到新房户型图（酷家乐截图、CAD、平面图都行），要出一套能落地的装修方案
- 自己有风格偏好（现代、奶油、轻奢、原木、极简），但不会配色和选材
- 想跟装修公司对方案，需要一份**标准的、可视化的、能直接拿去的方案书**

不适用：

- 硬装已完成、只做软装搭配（覆盖不到位）
- 商业空间、办公空间（逻辑不一样）
- 需要精确水电走线图、墙顶地施工图（这个得请专业设计师）

## 支持的图纸类型

用户上传的图纸可能有多种格式，Skill 会自动识别并采用对应的分析策略：

| 图纸类型 | 典型来源 | 主要能看出 | Skill 怎么用它 |
|---|---|---|---|
| **3D 立体图** | 酷家乐/三维家默认视图 | 空间比例、家具布局、动线 | 定家具摆放、软装搭配 |
| **效果图（渲染图）** | 装修公司提案 / AI 渲染 | 灯光氛围、材质质感、配色 | 提取配色和灯光方案 |
| **CAD 图纸** | 设计师施工图 | 精确尺寸、墙体门窗、点位 | 规划柜体、确认动线 |

**只发 1 张图时**：Skill 会主动声明"从图里看出了什么、看不出什么"，并请你补关键图纸。
**多张图混发时**：综合使用——CAD 拿尺寸 + 3D 看空间 + 效果图抄配色灯光。

识别图解和各类图纸的处理策略见 Wiki 的 [图纸类型识别](https://github.com/RichardWinters/renovation-color-design/wiki/Drawing-Types) 页面。

## 5 分钟上手

**第 1 步：触发 Skill**

告诉 WorkBuddy：

```
我要装修，帮我出一套配色方案。这是我的户型图 @image，风格偏好现代暖灰。
```

**第 2 步：提供户型信息**

- 户型图（酷家乐截图 / CAD / 手绘都行）
- 风格偏好（一句自然语言）
- 预算范围（可选）
- 所在地区（影响材料选择）

**第 3 步：等输出**

Skill 会同时输出三张图：

1. **色卡总览图** —— 60/30/10 比例条 + 色号标注
2. **四房间立面对比图** —— 每个房间的立面 + 标注
3. **全屋材料清单** —— 含品牌、规格、表面质感

**第 4 步：拿去买**

色号、规格、型号直接拿去建材店对。色卡图和立面图给装修公司负责人看，对方案。

## 核心设计原则

| 法则 | 内容 |
|------|------|
| 60-30-10 | 主色 60% / 辅色 30% / 点缀色 10% |
| 墙浅地中家具深 | 视觉重心下沉，有层次不飘 |
| 全屋统一 | 墙漆、地板、柜门、五金全屋各只一款 |
| 灯光分层 | 3000K 氛围 + 4000K 功能 |

详见 [`references/design_principles.md`](references/design_principles.md)。

## 风格模板

| 风格 | 主色 | 辅色 | 点缀 |
|------|------|------|------|
| 现代暖灰 | 菱花白 | 深胡桃 | 古铜金 |
| 奶油风 | 象牙白 | 奶咖 | 焦糖棕 |
| 极简黑灰 | 哑白 | 深灰 | 哑黑 |
| 原木风 | 米白 | 白橡木 | 牛油果绿 |
| 轻奢灰蓝 | 烟灰 | 雾霾蓝 | 黄铜 |

详见 [`SKILL.md`](SKILL.md) 的"风格速查表"章节。

## 表面质感决策（光面 vs 麻面）

三个问题定质感：

1. **沾水吗？** → 卫生间、厨房地面：**永远麻面**（防滑）
2. **沾油吗？** → 厨房台面、灶台背墙：**永远光面**（好擦）
3. **要反光吗？** → 客厅、卧室：要高级感用微光面，要温馨用哑光

详见 [`references/design_principles.md`](references/design_principles.md) 的"表面质感选择"章节。

## 安装

**方式一：作为 WorkBuddy Skill 安装**

```bash
# 个人 Skill 目录（用户级，所有项目可用）
cp -r renovation-color-design ~/.workbuddy/skills/

# 或项目级 Skill 目录（仅当前项目可用）
cp -r renovation-color-design .workbuddy/skills/
```

**方式二：在 WorkBuddy 中按需调用**

对话中提"装修配色"、"配色方案"、"选材料"等关键词即可自动触发。

## 验证是否生效

在 WorkBuddy 里说：

```
用 renovation-color-design skill 帮我看看 @image 这张户型图，配色怎么搞。
```

如果 Skill 已加载，会引用本仓库的色号库和决策表；如果没加载，会提示"未找到 skill"。
